# 🔐 Linux Server Auditor

Ferramenta em Python para realizar auditorias automatizadas em servidores Linux.

O projeto tem como objetivo coletar informações do sistema, analisar configurações e identificar possíveis problemas de infraestrutura e segurança.

## 🚧 Status

**Em desenvolvimento.**

Atualmente, o projeto possui a coleta de informações básicas do sistema:

- Hostname
- Sistema operacional
- Kernel
- Uso de CPU
- Uso de memória
- Uso de disco
- Uptime

Novas funcionalidades serão adicionadas durante o desenvolvimento.

## 🛠️ Tecnologias

- Python
- Linux
- psutil
